# ESHOP-INDUNI

Ce dépôt regroupe les outils internes Induni.

## Projets

### `gestion-soumissions/` — Gestion des soumissions

Outil interne de traitement des soumissions (appels d'offres / demandes de prix construction) : suivi des
soumissions, constitution de lots par corps de métier, sourcing de fournisseurs par catégorie, génération
d'e-mails de demande de prix, et dashboard de suivi des offres reçues.

Version web (backend Express/TypeScript/Prisma + frontend React/Vite) portée depuis un prototype HTML autonome.
Voir `gestion-soumissions/README.md` pour le détail et les instructions de démarrage.

### E-shop

Créer un eshop utilisable pour envoyer des commandes au fournisseur et faire le pilotage des commandes. Pas
encore démarré.
